# Internationalisierung (i18n)

Deutsch + Englisch, Deutsch ist Standard/Fallback. Mechanismus in `logbuch.js`, direkt nach
`esc()`:

- `STRINGS = { de: {...}, en: {...} }` – flache Keys mit Punkt-Namespace
  (`'auth.createAccount'`, `'habitForm.error.nameRequired'`, `'ariaLabel.*'` für
  Aria-Labels, `'error.db.*'` für `translateDbError`), beide Sprachblöcke in **identischer
  Key-Reihenfolge** zum leichten Diffen. Eine Start-Assertion vergleicht
  `Object.keys(STRINGS.de)` gegen `.en` und meldet jede Abweichung per `console.error`.
- `t(key, params)` liest aus `STRINGS[currentLocale]`, interpoliert `{platzhalter}` aus
  `params` (dabei automatisch `esc()`'t – Aufrufer escapen nicht selbst), fällt bei
  fehlendem Key auf Deutsch zurück und loggt eine Warnung. Das Template selbst bleibt
  unescaped (darf bewusst gesetztes HTML wie `<strong>` enthalten).
- **Meldungen sind reiner Text** (`state.notice`, `authError`, `unlockError` werden beim
  Anzeigen escaped) – Meldungen mit Parametern deshalb mit `tPlain()` bauen (escaped die
  Parameter nicht), sonst erscheinen sie doppelt escaped ("&amp;").
- `currentLocale` wird über `applyLocale(locale)` gesetzt (setzt auch
  `document.documentElement.lang`) – beim Start per `detectInitialLocale()`
  (Browser-Locale als Platzhalter), dann aus `user_settings.locale` (Check `de`/`en`,
  kontoweit, anders als das geräte-lokale Theme), änderbar in den Einstellungen
  (`saveLocale()`, gleiches Muster wie `saveDefaultReminderMinute()`). Die Bestätigungsmail
  bekommt die Sprache über Nutzer-Metadaten beim `signUp` (siehe
  [datenschutz-sicherheit.md](datenschutz-sicherheit.md)).
- Datum/Wochentage/Monatsnamen über `Intl.DateTimeFormat`-Helfer (`weekdayShort`/
  `weekdayLong`/`monthName`/`monthShort`/`longDate`/`formatDMY`, gecacht in `dtfCache`)
  statt fester Arrays. Die Montag-zuerst-**Reihenfolge** (`(d.getDay()+6)%7`) ist davon
  unberührt – nur die Labels ändern sich, nicht die Tages-Logik.
- `send-notifications` hat eine eigene, bewusst simple `PUSH_TEXTS`-Tabelle (siehe
  [erinnerungen.md](erinnerungen.md)).
- Feldnamen (frei vom Nutzer vergeben) sind bewusst **nicht** Teil davon – nur App-Texte
  werden übersetzt, nie Nutzerinhalte.
